ART BOOK FAIR LIM — 웹페이지 프로젝트

구성
- index.html : 메인 행사 안내 페이지
- registration.html : 사전등록 / 프로그램 신청 데모 페이지
- css/style.css : 모든 스타일
- js/main.js : 팝업, 모바일 메뉴, 신청 폼 동작
- assets/event-poster.png : 제공받은 행사 포스터 이미지
- assets/*.svg : 웹페이지에 직접 삽입한 책/잎사귀 일러스트 이미지

실행 방법
1. 압축을 해제합니다.
2. index.html 파일을 크롬 등 웹 브라우저에서 엽니다.
3. 메인 화면의 '전체 일정 보기', '전체 프로그램 보기' 버튼을 눌러 팝업을 확인합니다.
4. '사전등록' 버튼을 눌러 registration.html로 이동합니다.

참고
- 행사 일시와 장소, 작가명, 프로그램은 시안 제작을 위한 가상 정보입니다.
- 사전등록 폼은 프론트엔드 동작 예시이며, 실제 데이터 저장/전송은 구현되어 있지 않습니다.
- CSS와 JavaScript는 HTML과 별도 파일로 분리되어 있으며 주요 기능에 한국어 주석을 넣었습니다.
